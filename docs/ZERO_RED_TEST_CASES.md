# zero red 0.2 项目专用测试用例

基准日期：2026-11-07；基线是本次准备时的**当前工作区（含未提交改动）**，不是仅按旧文档或已提交版本。每次运行由准备脚本生成源码 SHA-256 清单，防止把旧云 Mac 结果用于当前源码。本文为待执行测试设计，不表示通过。

## 范围与验收依据

依据 `PRODUCT.md`、`FEATURE_MATRIX.md`、原生 Swift 源码、15 个现存 XCUITest 方法及 fixture；冲突时列为待确认项，不能以“源码这样实现”自动判为正确。主要追踪点：

| 模块 | 实现依据（相对仓库根） | 本轮重点 |
| --- | --- | --- |
| 浏览/页面 | apps/ios/ZeroRed/BrowserView.swift、BrowserEngine.swift、BrowserSession.swift、BrowserCore.swift | 极简首页、真实预览、独立导航；最多 50 页；最多常驻 6 个 WebView；最近关闭最多 10 项 |
| 阅读 | apps/ios/ZeroRed/PageScripts.swift、ReaderView.swift、ReadingLibrary.swift | 当前页完整可见文本、全屏阅读、专注模式图标缓存、文档原件与备份 |
| 视频 | apps/ios/ZeroRed/PageScripts.swift、NativePlayer.swift、LibraryView.swift | 网页直接播放/页面全屏/iframe/菜单入口统一 NativePlayer；重复打开、点击暂停、缓存按钮统一显隐 |
| 下载 | apps/ios/ZeroRed/DownloadManager.swift、StreamingDownloads.swift | 普通文件/MP4/MOV 后台任务及 HLS；重试竞态、离线实际可播 |
| 隐私/设置 | apps/ios/ZeroRed/LibraryStore.swift、SettingsView.swift、BrowserSession.swift | nonPersistent 无痕、分站清理、基础拦截、权限与设置落地 |
| 系统集成 | apps/ios/ZeroRed/ZeroRedApp.swift、BrowserView.swift、Info.plist、Configuration | 文档与 zerored scheme；默认浏览器 entitlement 尚未启用 |

**明确排除**：账号登录系统、跨设备同步、付费订阅、AI 摘要、OCR、旧 `.doc` 支持、iPad 多窗口专项。网站自身登录仍需测试。iPhone 为目标设备，iOS 27 是当前目标验证环境；工程最低部署版本从 `project.pbxproj` 读取并记录，不能把编译可安装等同于各系统验收通过。

**不作通用承诺**：DRM、blob/MSE、特殊鉴权流通用下载；所有第三方网站兼容；后台永远不被系统终止；无痕等于匿名上网；未经授权可设为默认浏览器。

**恢复边界**：会话恢复目标为 URL/导航历史/滚动位置，不要求还原 POST、表单草稿及全部 JS 状态。保存的阅读文档、书签、设置、已完成文件应持久化。无痕标签不写入恢复或最近关闭；显式结束无痕会话应销毁其站点数据。主动保存/导出无痕文档或视频的保留政策需确认，见执行指南待确认项。

## 执行约定

- P0：核心浏览、数据一致性、隐私和安全；P1：主要功能和异常恢复；P2：体验细节。优先级不同于缺陷严重度。
- **S**＝Mac/iPhone 模拟器可测；**D**＝必须 iPhone 真机验收，可先模拟器探索；**E**＝需外部资源或授权。每条 ID 及每种参数组合独立留记录。
- 所有用例默认全新**测试专用沙盒**、正常网络、受控 fixture 正常、中文或英文按记录选择。升级和持久化测试除外；禁止清除开发者或用户日常资料库。
- 表格“数据/前置”引用执行指南中的 F1–F9 数据集。未标注方法名的测试均为待人工执行/待补自动化，不能因单元测试通过而代替验收。
- 预期是验收目标；如果当前实现违反目标，记录缺陷或待产品裁决，不修改预期来迎合实现。
