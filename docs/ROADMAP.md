# 后续开发与验收

## 当前已有

- 原生 iOS 功能实现稿、网页交互预览、测试与功能覆盖表。
- 54 项 Swift 核心测试及 73 项网页单元测试的已记录通过结果。
- macOS CI 配置和本地 Xcode 验证脚本。

## 优先完成

1. 已完成：Xcode 27 整包 Debug/Release 模拟器编译，修复 Apple SDK 调用及架构配置问题。
2. 已完成：iOS 27 / iPhone 18 Pro 模拟器 8 项 XCUITest 全通过，Release 静态分析通过；后续处理已记录的音频主线程和 SwiftUI 状态发布警告。
3. 在 iOS 27 真机验证权限、上传、系统翻译、AirPlay、PiP、HLS 与后台下载。
4. 建立目标网站清单，验收登录、支付返回、验证码、授权登录、弹窗和视频兼容性。
5. 执行网页浏览器点击回归、离线重开、触屏、键盘和存储异常测试。
6. 完成 VoiceOver、动态字体、横屏、弱网、低内存、低存储测试。
7. 由账号持有人申请默认浏览器资格，批准后配置 entitlement 和签名。
8. 准备 App 图标、隐私说明、商店素材及发布签名。

不得在以上验收前把项目标记为已适配全部网站、已验证 iOS 27 或已可作为系统默认浏览器。
