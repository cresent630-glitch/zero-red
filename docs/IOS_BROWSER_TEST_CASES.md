# iOS 浏览器 APP 用户视角测试用例与验收方案

> 通用参考稿，已由 [zero red 项目专用测试用例](ZERO_RED_TEST_CASES.md) 替代为执行入口。本文件中的账号同步、iPad 多窗口等不属于当前项目范围，不直接用于 zero red 验收。执行准备见 [ZERO_RED_TEST_EXECUTION.md](ZERO_RED_TEST_EXECUTION.md)。

版本：1.0；编制日期：2026-11-07。适用于独立 iOS 浏览器 APP，以用户可见行为为验收依据。本文件是待执行用例，不代表测试已经完成。

## 1. 范围、约定与使用方法

覆盖安装升级、浏览搜索、标签、网页交互、数据管理、下载、多媒体、隐私安全、系统集成、兼容性、无障碍及可靠性。未提供具体产品需求，因此以下是通用基线，执行前需补充 APP 名称、版本、最低支持系统、支持设备、功能清单、数据保留承诺和性能目标。

- **基础**：常规浏览器应评估的场景；若实现不同，依据已确认的产品规格调整预期并留痕。
- **条件**：仅在产品提供该功能、对应系统/地区支持或已声明支持时执行；否则标记 N/A 并说明依据。不得将未实现的可选功能直接判定为缺陷。
- **P0**：核心访问不可用、数据损坏、隐私泄露、错误安全判断等发布阻断风险。
- **P1**：重要功能、异常恢复、兼容性或高频操作问题。
- **P2**：低频功能、体验细节或可替代操作路径。优先级用于执行排序，不等同于缺陷严重度。
- “符合约定”必须引用已批准的具体规则；无规则时记为“待确认”，不能直接通过。重载后表单草稿、无痕标签恢复、跨域跳转、下载后台行为等尤其需要明确。
- 无痕模式仅按产品承诺验证本地数据隔离和保留行为，不承诺向网站、网络运营方或下载文件隐藏用户活动。
- 用例默认真机、全新或已重置的独立测试账号、正常网络、测试站点可用；其他前置条件列在表内。每条独立执行并清理数据，避免前一条污染后一条。
- 表格中用分号连接的操作按从左到右执行。组合参数须分别生成执行记录，不能一次成功代表所有参数通过。

## 2. 测试环境与受控数据

### 2.1 环境矩阵

| 维度 | 最低覆盖要求 |
| --- | --- |
| 系统 | 最低支持大版本及最新补丁、每个在支持范围内的中间大版本、当前正式大版本及最新补丁；Beta 单独探索，不混入正式验收 |
| 设备 | 最低支持/低内存 iPhone、主流 iPhone、大屏 iPhone；覆盖不同安全区和刷新率；支持 iPad 时增加小/大屏及产品支持的多任务窗口模式 |
| 安装状态 | 全新安装、当前线上版升级、支持的较旧版本跨版本升级、卸载重装；保留一台真实长期使用设备 |
| 网络 | Wi-Fi、蜂窝、IPv6-only/DNS64-NAT64、无网、弱网、网络切换、认证热点；按支持范围增加 VPN/代理 |
| 用户状态 | 未登录、账号 A、账号 B、凭据过期；普通/无痕；首次/已拒绝/已允许权限 |
| 系统设置 | 浅/深色、中文/英文、产品支持的 RTL 语言、最大辅助字体、VoiceOver、减少动态效果、低电量、有限存储 |

关键 P0 在最低配置、主流配置和最新正式系统上全测；其他组合按风险和两两组合覆盖。iPad、多窗口、地区特有能力、浏览器内核差异应按发行版本分别建立适用清单。涉及系统回收、后台、权限、相机和耗电的项目必须真机验收。

### 2.2 测试站点与数据集

使用自有 HTTPS 测试站点及可控服务端，保留访问日志和请求计数；不得在真实金融、生产支付或不明恶意站点测试。

| 数据编号 | 内容 |
| --- | --- |
| D1 导航站 | 页面 A/B/C、锚点、长页面、301/302/307/308、跳转循环、404/500/503、慢响应；跨域站点独立部署 |
| D2 输入站 | 中英文/Emoji/组合字符、RTL、超长 URL、空白/换行、编码参数、IDN 域名、搜索保留字符；保存原始请求以核对编码 |
| D3 会话站 | 账号 A/B、Cookie/Session/localStorage/IndexedDB、退出登录、会话过期、跨站登录测试；不同站点和路径 |
| D4 交互站 | GET/POST 表单、计数提交接口、文件上传、弹窗、iframe、文件选择、相机/定位/麦克风申请；支持幂等性观察 |
| D5 下载站 | 0 B、1 KB、10 MB、100 MB、1 GB 文件；已知 SHA-256；同名/中文/无扩展名/危险文件名、重定向、断点支持与不支持、鉴权过期 |
| D6 多媒体站 | 长短视频、音频、全屏、字幕、倍速、直播与异常流；画中画/后台音频按声明支持测试 |
| D7 安全站 | 自有过期/域名不匹配/不可信证书、HTTP/HTTPS 混合资源、同形域名、安全提示伪装、来源跳转；仅隔离测试环境 |
| D8 页面兼容集 | 静态文章、响应式页面、SPA、长列表、Canvas/WebGL、富文本编辑、WebSocket/SSE、缓存/离线页；仅验证产品声明支持的 Web 能力 |
| D9 用户资产 | 100/1,000/10,000 条书签和历史、嵌套文件夹、同名项目、100 个标签（或产品上限）；全部使用合成数据 |

弱网建议配置：下行 512 Kbps、上行 128 Kbps、RTT 400 ms、丢包 5%；极弱网配置：128/64 Kbps、RTT 1,000 ms、丢包 10%。这些是测试配置，不是系统标准；记录实际生效参数。可用 Network Link Conditioner 或实验室网络设备构造网络条件，真机操作步骤依系统版本确认。[Apple 网络条件测试说明](https://developer.apple.com/videos/play/tech-talks/111378/)

## 4. 可量化验收口径

以下数值是**建议初始门槛，需产品和测试负责人确认**，并非 Apple 强制标准。最低支持机型若使用不同预算，需在执行前明确，不能测完后为通过而调整。

| 指标 | 建议门槛 | 测量定义 |
| --- | --- | --- |
| 冷启动 | P95 ≤ 3 秒 | 从用户点图标至地址栏及主操作可交互；受控设备，不含系统安装后特殊准备；首次启动单独报 |
| 热启动 | P95 ≤ 1 秒 | 后台进程仍存活，从切回至主 UI 可交互 |
| 新建/切换标签 | P95 ≤ 500 ms | 点击至目标标签 UI 可交互；已加载标签切换与被回收重载分别统计 |
| 输入响应 | P95 ≤ 100 ms | 按键/输入事件至字符展示；中文组合输入单列，不计人工选词时间 |
| 卡死 | 0 次无法恢复；主线程可感知停顿 > 2 秒均排查 | 通过屏幕录像、事件与性能记录定位；网络等待期间 UI 仍应可交互 |
| 普通网页加载 | 受控简单页正常 Wi-Fi 首次可用 P95 ≤ 3 秒 | 从导航提交至主内容可见且主要操作有效；固定站点、缓存冷/热分开，不把公网差异混为 APP 缺陷 |
| 性能回退 | 核心 P95 相对基线恶化不超过 10% | 同机同环境同脚本；超差重复复核并评审原因 |
| 内存稳定性 | 固定周期后可回归稳定区间，无持续单调增长 | 热身后取基线，循环并关闭标签后采样；绝对上限按机型制定，不能只用单次峰值判断泄漏 |
| 电量/温度 | 同脚本耗电相对基线恶化不超过 10%；无异常热退出 | 同电池健康、环境温度、亮度、音量与网络；至少 3 轮取中位数；温度工具与采样点固定 |
| 同步时限（条件） | 正常网下建议 ≤ 30 秒 | 从一端确认保存至另一端可见；离线积压、服务故障另报 |
| 可靠性 | 本测试范围 0 次未解决崩溃、不可恢复卡死、确认资产丢失或隐私泄露 | 功能套件、压力及长稳均纳入；不能据此宣称线上崩溃率为零 |

每项性能至少 30 个有效样本，记录每个原始值、样本数量、失败/超时数量、P50/P95 和最大值。建议用最近秩法计算 P95（排序后第 ceil(0.95×N) 个样本）。失败/超时不得静默剔除，单列失败率及原因；只有测量设备故障等预先定义的无效样本可排除。临界值增加样本复核。

## 5. 长稳与异常恢复执行脚本

### 5.1 8 小时混合使用

每 20 分钟一轮，共 24 轮：浏览 5 个受控网页并滚动；搜索 3 次；开关 10 个标签；编辑并提交 1 次计数表单；新增/修改/删除书签各 1 次；播放视频 2 分钟；支持下载时下载 10 MB 并校验；切后台 1 分钟后返回。每 4 轮执行一次断网→恢复和普通/无痕隔离检查；网络注入时使用测试账号。

每轮记录：当前标签数、书签集合摘要、服务端提交计数、进程内存、CPU、耗电、温度状态、失败操作与恢复耗时。每 2 小时截图并检查存储/会话一致性。发生崩溃或卡死立即保留证据，不静默重启后记为通过；修复后重新执行相关阶段。

### 5.2 24 小时保留与恢复

建立 20 个普通标签、2 个无痕标签、已保存书签和按规则可恢复的下载任务。锁屏/待机后按 1/8/24 小时检查。分别记录进程存活和被系统回收情形；不要求系统保证 APP 在后台常驻。检查资产、身份、无痕政策、页面可重载性和后台异常耗电。

### 5.3 破坏性恢复矩阵

将“导航、计数表单提交、保存书签、删除历史、下载、同步、无痕会话结束”分别与“断网、切网、后台、锁屏、手动结束、系统回收、低存储”配对。适用配对至少一次；P0 数据边界每组至少重复 20 次。记录故障发生在操作前、进行中还是确认成功后，使用操作前后资产快照、文件哈希和服务端计数核对结果。

系统回收与手动划掉 APP 是不同条件，应分别记录；无法稳定触发的系统事件标记“未覆盖/受限”，不得以手动结束进程替代后直接通过。

### 6.2 每版冒烟与完整回归

每个候选包先执行：A01/A04/A07、B01/B02/B07/B11、C01/C09、D04/D05/D09、E01/E07、H04/H05/H07/H11、L01/L05/L15；有下载/默认浏览器/同步则追加 F01/F06、I01/I03、J02/J03。冒烟失败先阻断扩大发布，再根据缺陷影响继续其他独立测试。

完整回归执行所有适用用例及参数矩阵，重点复测本版修改模块和依赖路径。隐私存储、生命周期、内核或数据库变更，需要额外覆盖无痕、升级迁移和异常退出恢复。

### 6.3 建议发布门槛

1. 已确认适用范围内的 P0/P1 全部执行且通过；隐私、数据一致性、关键恢复用例无阻塞和未执行项。
2. 无未关闭 S0/S1；影响隐私、资产安全或核心访问的缺陷不得仅通过书面接受绕过。其他缺陷有明确责任人和风险决定。
3. 所有适用用例有结论；P2 未通过项逐项评审。N/A 不计入通过数，阻塞和未执行不能计为通过；同时报告执行覆盖率与通过率，避免只看通过率。
4. 8 小时长稳、24 小时保留、最低配置性能和升级迁移验收完成；修复后的复测与必要回归通过。
5. 测试报告列出设备/系统/网络覆盖、所有遗留风险和未覆盖项。上线后按产品已有监控流程观察崩溃、启动、页面失败、下载失败与反馈，必要时分阶段发布。

有限用例无法证明不存在任何缺陷。本方案用于系统覆盖用户风险；只有执行证据和明确验收门槛共同满足，才能支持本次版本的可用性与可靠性结论。

## 7. 可选功能补充规则

如产品包含 VPN、AI 搜索/摘要、翻译、订阅付费、广告激励、云盘、推送、扩展或企业证书，应分别补充独立用例。至少覆盖开通/取消/失败、权限和数据流、离线/超时、跨账号隔离、升级迁移与隐私退出路径。付费需使用沙盒验证购买、恢复、取消、退款后权益及服务端一致性；AI/翻译需验证原文隐私、流式中断、错误提示、内容正确性及来源展示。上述功能不在本通用核心套件中默认判定为已覆盖。
